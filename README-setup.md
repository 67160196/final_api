# ชุดติดตั้งสภาพแวดล้อม ข้อสอบปลายภาค 88736065

ชุดนี้ใช้ติดตั้งและทดสอบสภาพแวดล้อมก่อนวันสอบ พร้อมตัวอย่าง CRUD API สำหรับจัดการเมนูอาหาร

## ขั้นตอน

1. ติดตั้ง Docker Desktop และ Node.js ให้พร้อมใช้งาน
2. คัดลอก `.env.example` เป็น `.env`
3. เปิดฐานข้อมูล: `docker compose up -d` (รอประมาณ 20 วินาที)
4. ติดตั้ง dependency: `npm install`
5. ใส่ข้อมูลตัวอย่าง: `npm run seed`
6. ตรวจการเชื่อมต่อ: `npm run check` ควรแสดงว่าเชื่อมต่อได้และพบเมนู 22 รายการ
7. ทดสอบเครื่องมือและ CRUD API: `npm test` ควรผ่านทั้งเทสต์สภาพแวดล้อมและเทสต์ routes
8. เริ่ม API ตัวอย่าง: `npm start` แล้วเรียก CRUD เมนูที่ `/menu`

## CRUD เมนู

| Method | Path | ใช้ทำอะไร |
| --- | --- | --- |
| `GET` | `/menu` | ดูเมนูทั้งหมด |
| `GET` | `/menu/:id` | ดูเมนูตาม id |
| `POST` | `/menu` | เพิ่มเมนู โดยส่ง `name` และ `price` |
| `PUT` | `/menu/:id` | แก้ไขเมนู โดยส่ง `name` และ `price` |
| `DELETE` | `/menu/:id` | ลบเมนู |

ทดสอบ routes โดยไม่ต่อฐานข้อมูลด้วย `npx jest tests/menu.test.js`.

## หมายเหตุ

- ถ้าพอร์ต 3309 ถูกใช้อยู่ ให้เปลี่ยนค่า `DB_PORT` ใน `.env` และพอร์ตใน `docker-compose.yml` ให้ตรงกัน
- ถ้าต้องการหยุดฐานข้อมูล ให้รัน `docker compose down`
